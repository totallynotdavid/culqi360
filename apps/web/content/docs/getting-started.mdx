# Primeros pasos

Bienvenido al sistema de gestión. Esta guía explica cómo comenzar a usarlo desde
cero.

## Acceder al sistema

1. Abre la aplicación en tu navegador
2. Ingresa tu nombre de usuario y contraseña
3. Si es tu primera vez, el sistema te guiará por la configuración inicial de tu
   perfil

## Navegar por las secciones

El menú lateral izquierdo agrupa las secciones principales:

- **Dashboard:** resumen de actividad reciente y métricas del equipo
- **Contactos:** registro de clientes, proveedores y personas del equipo
- **Inventario:** productos, materiales y control de stock
- **Agenda:** eventos, llamadas y reuniones programadas
- **Ventas:** oportunidades y seguimiento comercial

## Buscar registros

Usa la barra de búsqueda en la parte superior para encontrar cualquier registro
por nombre, código o descripción. La búsqueda funciona en tiempo real.

## Crear un registro nuevo

En cada sección, el botón **+** o **Nuevo** en la esquina superior derecha abre
el formulario de creación. Completa los campos requeridos y guarda.

## Necesitas ayuda

Contacta al administrador del sistema para soporte técnico o dudas sobre el uso
de una funcionalidad específica.
