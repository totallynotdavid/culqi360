# Terminology

The web interface is in Spanish. These terms are fixed. Code uses English names
and says `lead` where the interface says cliente.

| Term                     | Meaning                                                                                                                           |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| **Cliente**              | The record that moves through the commercial workflow. The interface never shows `lead`.                                          |
| **Comercio**             | The RUC reported in GPV and attribution dashboards.                                                                               |
| **Empresa**              | The legal organization, or a company-specific action such as adding it to favorites. It is not a synonym for cliente or comercio. |
| **Clientes activos**     | The active-assignment limit.                                                                                                      |
| **Asignaciones diarias** | The number of new client assignments available each day.                                                                          |
| **Límite de sucursal**   | A limit that teams inherit.                                                                                                       |
| **Límite personalizado** | A user-specific exception to the inherited limit.                                                                                 |

Product names, file extensions, and technical values that a user must type stay
as they are. All other interface text is Spanish.
